# React Game Development Examples

Complete working examples for React-based web game development.

## Examples

### [Basic Game Loop](game-loop/)
Example of a game loop using requestAnimationFrame with React hooks.

### [3D Board](3d-board/)
Simple 3D board rendering using React Three Fiber.

### [Character Creator](character-creator/)
Complete character creator component with shape and color selection.

### [State Management](state-management/)
Zustand store examples for game state management.

## Usage

Each example includes:
- Complete, runnable code
- Detailed comments
- Usage instructions
- Expected behavior

## Getting Started

1. Copy example code into your React project
2. Install required dependencies
3. Import and use components
4. Customize as needed

## Dependencies

Common dependencies across examples:
- React 18+
- @react-three/fiber (for 3D examples)
- three (for 3D examples)
- zustand (for state management examples)
- framer-motion (for animations)

See individual example READMEs for specific requirements.
